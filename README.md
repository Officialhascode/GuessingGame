# Number Guessing Game 🔢

## Description ⌨️
A fun and interactive Python game where players try to guess a randomly generated number!

## Features ✨
- Random number generation between 1-100
- Tracks number of attempts
- Provides "too high" or "too low" hints
- Victory message with attempt count
- Input validation for non-number entries

## How to Play 🎮
- The game generates a random number between 1 and 100
- Enter your guess when prompted
- Receive feedback if your guess is too high or too low
- Keep guessing until you find the correct number
- See how many attempts it took you to win!
